# 智能记账

## 作者说明

这是一个基于多模态大模型的记账工具。它可以根据自然语言输入，或类似盒马、淘宝/天猫这类包含多个商品的订单截图，自动拆分账目并分类记账。你可以自行配置兼容的大模型服务，也可以联系作者申请内测账号体验云端模型代理。所有账单数据默认保存在本地，支持账单数据分析，以及在数据足够时进行跨月消费分析。

下面是 AI 辅助整理的项目说明。

## 项目说明

智能记账是一款本地优先的 Android 记账工具。它可以根据自然语言输入，或类似盒马、淘宝/天猫这类包含多个商品的订单截图，自动拆分账目、识别金额、归类消费，并生成可核对的本地账单。

项目基于多模态大模型能力实现截图理解，默认推荐使用 `mimo-v2.5`。使用者可以自行配置 API Key、接口地址和模型名称；小范围内测用户也可以联系作者申请云端服务账号，由服务端代为调用模型接口。账单数据默认保存在本机。

这个项目更适合作为开源工具、个人效率工具或二次开发基础，而不是面向普通用户的免配置商业化 App。

## 适合谁

- 想用视觉模型识别账单截图的人。
- 希望账单数据默认保存在本机的人。
- 愿意自行配置 API Key、接口地址和模型名称的人。
- 想联系作者申请内测账号体验云端模型代理的人。
- 想研究 React、Capacitor Android 和 AI 记账应用实现的人。

## 不适合谁

- 不想配置模型接口、也没有内测账号的普通用户。
- 需要云同步、多端账号或多人共享账本的人。
- 希望识别结果完全自动入账、不做人工核对的人。

## 功能

- **自然语言记账**：从一句话中提取金额、分类、日期、备注和标签。
- **AA 净支出**：多人分摊时记录自己最终承担的金额，实际回款优先于平均分摊。
- **截图识别**：接入视觉模型后，可识别账单截图并生成结构化账单。
- **盒马订单拆分**：盒马截图会保存为一条父账单，展开后查看商品小项、数量、单位、金额和分类。
- **淘宝/天猫订单识别**：按订单或商品分别记录，优先使用实付款金额。
- **明细管理**：支持搜索、分类筛选、展开详情、修改分类/日期/标签、编辑商品子项、单条删除和批量删除。
- **预算仪表盘**：展示月度支出、预算进度、周趋势、分类结构、标签汇总和日历视图。
- **智能洞察**：在数据足够时，生成跨月消费、分类变化和预算使用情况分析。
- **模型配置**：支持自定义 API Key、Base URL 和模型名称。
- **云端服务**：支持登录内测账号后通过服务端模型代理解析文字和图片，App 不暴露模型 API Key。
- **模型能力测试**：可测试文字、JSON 和图片能力，便于判断当前模型是否适合截图记账。
- **本地优先**：账单、设置、预算和分类默认保存在 LocalStorage。

## 模型配置

默认配置为：

```text
Base URL: https://api.xiaomimimo.com
Model: mimo-v2.5
```

也可以改成其他兼容 OpenAI Chat Completions 风格的模型服务。截图识别建议使用支持图片理解的视觉模型；如果使用纯文本模型，图片拆单、商品数量和单位识别可能不完整。

如果你想体验作者维护的云端模型代理，可以联系作者申请内测账号。云端服务仅用于模型调用代理和用量控制，不提供云备份或多端同步；账单仍默认保存在本机。

## 安装

从 GitHub Releases 下载最新版 APK：

```text
jizhang-v1.4.3-debug.apk
```

安装后进入设置页。你可以选择自填模型，填写自己的 API Key、接口地址和模型名称；也可以在获得内测账号后登录云端服务。配置后可使用“测试文字 / JSON / 图片能力”或“云端连接诊断”确认服务可用。

更详细的安装与配置说明见 [docs/SETUP.md](docs/SETUP.md)。

## 数据与隐私

- 新用户首次安装后账本为空，不写入测试数据。
- 老用户升级后保留已有真实账单、设置、API Key、预算和分类。
- 截图识别会把图片发送到你配置或登录的模型服务。
- 使用云端模型代理时，服务端会接收必要的解析请求并记录账号、接口、模型、成功状态和用量，不保存完整账单文本或图片内容。
- 项目作者不会从自填模型模式接收或保存你的账单、截图或 API Key。

请在使用前阅读 [PRIVACY.md](PRIVACY.md) 和 [DISCLAIMER.md](DISCLAIMER.md)。

## 本地开发

```bash
npm install
npm run dev
```

默认预览地址：

```text
http://127.0.0.1:5173/
```

开发预览可以在项目根目录放置 `key.txt`，用于本地代理测试模型接口。`key.txt` 已被 `.gitignore` 忽略，不应提交到仓库。

## 构建

```bash
npm run build
```

## Android 构建

同步 Android 工程：

```bash
npm run android:sync
```

构建 debug APK：

```powershell
cd android
.\gradlew.bat assembleDebug
```

如果自编译时需要接入自己的云端模型代理，可在构建前设置 `VITE_CLOUD_BASE_URL`。公开源码和文档不会内置作者服务器地址。

APK 输出路径：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

当前 Android 版本：

- `versionCode`: `14`
- `versionName`: `1.4.3`
