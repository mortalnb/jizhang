# 安装与配置

本文面向 `v1.5.0-rc.2` 在线测试用户。

## 1. 升级安装

1. 下载 `jizhang-v1.5.0-rc.2-debug.apk`。
2. 直接覆盖安装旧版，不要先卸载或清除应用数据。
3. 首次打开后先进入明细页确认旧账仍在，再导出一份账本备份。

新版会把 schema 3/4 账本迁移到 schema 5。迁移前会保留原始恢复快照；金额、日期、描述和分类不变，历史支付方式字段会移除，旧标签只做单值兼容。旧版因可选字段导致的错误校验不再把正常账本判为损坏。

## 2. 智能服务

设置页提供两种模式：

- **自填模型**：填写 MiMo API Key，默认地址 `https://api.xiaomimimo.com`、模型 `mimo-v2.5`。
- **云端服务**：使用作者提供的内测账号，模型 Key 保留在服务端。

文字和图片使用 `mimo-v2.5`；应用内语音固定使用 `mimo-v2.5-asr`。语音不复用输入法的听写功能。

## 3. 应用内语音

1. 进入“记一笔”，点击“应用内语音”。
2. 同意 Android 麦克风权限。
3. 说完后点击停止；最长 60 秒，到时自动停止。
4. 等待 MiMo ASR 返回文字。
5. 修改转写文字后点击“解析”。
6. 核对每一笔确认卡，再统一入账。

录音会转换为 16 kHz 单声道 WAV，并发送到自填 MiMo 服务或云端代理；应用不把录音保存到账本。

## 4. 批量文字与截图

- 一段文字中有不同日期时，应看到多张确认卡。
- 超市的一次结账应看到一张父卡和商品明细。
- 淘宝多个订单或不同日期应看到多张卡。
- 可用“商品展开为多笔”或“手动合并为一笔”纠正模型判断。
- 商品合计与实付不同不等于错误：优惠、运费或漏识别都可能造成差额，父级金额以可编辑的实付为准。

## 5. 云同步

云同步默认关闭。使用步骤：

1. 在设置页登录云端服务。
2. 打开“同步本地账本到云端”。
3. 若云端为空，应用上传当前本地快照。
4. 若云端已有不同账本，自动同步暂停，必须选择：
   - 推荐“合并云端与本机”：同 ID 保留本机，只补云端独有记录；
   - 只有明确知道哪一端应完整取代另一端时，才使用“用本机覆盖云端”或“从云端覆盖本机”。

从云端恢复前会创建本地恢复快照，但仍建议先手动导出。退出云端账号会关闭同步，不会自动删除已有云快照。

如果手头备份早于当前设备账本（例如备份后又新增了消费），不要选择覆盖恢复。设置页导入后应选择“合并并保留现有”；同 ID 记录保留当前版本，只补入备份中缺少的记录。

## 6. 建议在线测试清单

- 连续录入两条不同日期的消费，确认生成两笔、保存后仍停留在输入页且不进入恢复模式；快速双击确认也只能写入一次。
- 录入沃尔玛同一次结账，确认只占明细列表一行并可展开商品。
- 导入淘宝多订单截图，确认不同订单不被合并。
- 录一段包含两笔消费的语音，修改转写文字后解析、保存。
- 开启云同步，新增一笔后检查同步状态的版本号与时间。
- 导出本地备份，再测试云端恢复确认流程。
- 在明细中搜索折叠商品名并切换商户筛选，确认父账单可被找到；界面中不应再出现支付方式。

识别结果始终需要人工核对；出现异常时请保留输入样例、截图类型、应用版本和错误提示。
