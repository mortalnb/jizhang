# 安装与配置

本文面向从 GitHub Release 下载 APK 的用户。

## 1. 安装 APK

1. 在 GitHub Releases 下载最新版 APK。
2. 将 APK 传到 Android 设备。
3. 打开 APK 安装。
4. 如果系统提示“禁止安装未知来源应用”，请按系统提示为当前文件管理器或浏览器开启安装权限。

## 2. 配置模型

打开应用后进入“设置”页，填写：

- API Key
- 接口地址
- 模型名称

默认模型配置为：

```text
Base URL: https://api.xiaomimimo.com
Model: mimo-v2.5
```

你也可以配置其他兼容 OpenAI Chat Completions 风格的模型服务。

## 3. 测试模型能力

设置页提供“测试文字 / JSON / 图片能力”按钮。

建议至少确认：

- 文字可用
- JSON 可用
- 图片可用

如果图片能力不可用，截图识别和订单拆单可能无法正常工作。

## 4. 使用截图识别

1. 进入 AI 记账页。
2. 点击导入截图。
3. 等待模型识别。
4. 核对金额、分类、数量和单位。
5. 确认入账。

盒马订单会保存为一条父账单，展开后查看商品小项。淘宝/天猫订单会分别记录。

## 5. 常见问题

### 没有识别结果

请检查：

- API Key 是否正确。
- 接口地址是否正确。
- 模型名称是否正确。
- 模型是否支持图片输入。
- 网络是否能访问模型服务。

### 金额或分类不准确

AI 识别不是百分百可靠。请在保存前手动修改金额、分类、备注和标签。

### 新安装后为什么没有数据

这是预期行为。应用不会写入测试账单，新用户账本默认为空。

### 老用户升级会丢数据吗

正常升级会保留本地真实账单、设置、API Key、预算和分类。卸载应用、清除应用数据或清理 WebView 存储可能导致数据丢失。
